# 7-Zip SDK codec sources

This directory contains unchanged sources from the official 7-Zip 26.02
source release:

- Tag: `26.02`
- Commit: `f9d78aff31a5f2521ae7ddbdc97c4a8855808959`
- Upstream: <https://github.com/ip7z/7zip>

The source files identify Igor Pavlov as their author and are released to the
public domain. Only the files required by native codec backends are included.
Project-owned allocation and streaming shims remain in their respective Go
package directories.

`asm/x86/LzmaDecOpt.asm` is the baseline x86-64 decoder loop used by 7-Zip. It
does not require optional SSE or AVX instructions. The Windows AMD64 COFF
object is generated by
`../lzmadec/asmwin64/generate_windows_amd64.ps1`; GNU `objcopy` clears the COFF
timestamp so repeated builds are byte-for-byte reproducible.
The checked-in `lzma_dec_opt_windows_amd64.syso` has SHA-256
`df85dcfb303d48754f64fdb878a5ff2bbdb31f300698ff4f43e1682c3a725def`.
